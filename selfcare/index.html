What to point at during the demo

  • Scope is real, not cosmetic. The same account looks different to each persona because each file only holds what that role is allowed to see. The operator view refuses payment and plan changes with a hand-off to the CRM rather than a permissions error.
  • Missing data is declared, never invented. Two sites stopped reporting on 18 July and one usage record fell outside the retention window. Those appear as Not measured, hatched chart bars and an unattributed €1,840 in chargeback — never as zero.
  • Lifecycle actions carry impact context. Deactivating a user, swapping a SIM, paying an invoice and approving a request each state what changes, what it costs and what cannot be undone before the confirm button becomes live.
  • AI is confined and sourced. Orange appears only on AI surfaces. Every insight carries a confidence label and every assistant answer cites which record sets it read — and says so plainly when the evidence is not there.
  • State is never colour alone. Status pills carry a glyph, capacity meters carry a pattern, and topology links differ by dash style, so the screens survive a monochrome projector and a colour-blind audience.
Synthetic data throughout — no real customer, user or billing records. Built to the nim-ui-design-system-v2 visual contract. The official 6D mark renders only from the approved brand asset; it is never reconstructed in text, CSS or SVG.
