## Decisions

| Item | Decision |
|---|---|
| Component tests | Add `jsdom` and `@testing-library/react` (+ `@testing-library/user-event`) as **devDependencies only**. Component tests are `*.dom.test.tsx`, run in jsdom via `environmentMatchGlobs`; every existing test stays in Node. |
| AccountTabs orientation | `aria-orientation` follows the layout: `vertical` when `(min-width: 1024px)` matches, else `horizontal`, via `matchMedia` with a listener. |
| Dialog Escape | The top dialog's Escape handler calls `stopPropagation()` and `preventDefault()` after closing, so a document listener beneath it (account menu, cart drawer) does not also close. |
| Order line picture | Order items carry `product_id`; show the product's own image when the shop's product data has one (through a repo read, cached), else the category artwork the shop already uses (`categoryVisual`), never a generic box. |
| Rewards bar | The fill's light end must reach ≥ 3:1 against the track (WCAG 1.4.11): darken the cyan end / lighten the track; guard the pair in `contrast.test.ts`. |
| Waiting chip under search | Applications become searchable by the fields they have (company/applicant name, email, country — whatever the row carries); the Waiting count follows the search like the others. |
| Requisition unit_price | Database check (new migration, user applies): an ordinary requisition line (no `quote_line_id`, no `bundle_selection_id`) must carry the price-book price for the requisition's currency at the moment it is written; refused with a sentence otherwise. Separate branch `requisition-price-check`; not merged until applied and tested. |
| Main chunk | Split by persona with `React.lazy` + `Suspense` around each console's root and the heavy public pages; warning gone or the remaining largest chunk named. |

## Constraints

No change to behaviour beyond each item; no new runtime dependencies; WCAG 2.2 AA (`contrast.test.ts`);
44px controls; reduced motion; pure modules never import `supabase`. Gates per task: `npx vitest run`
(only `gateway.test.ts` financingProblem and `partnerApplication.test.ts` '02 Aug 2026' may fail) and
`npm run build`. Commits: plain-English subject, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
Parallel worktrees run `npm ci` inside the worktree.
